## 📄 Descripción del Proyecto
Este repositorio contiene la entrega final del *Proyecto Integrador. El objetivo del proyecto es el diseño, normalización y análisis de datos para un **Sistema de Gestión de Servicio Dental*, optimizando el control de pacientes, citas, tratamientos y registros clínicos.


## 📁 Estructura del Repositorio

 Archivos y Descripciónes
| README.md  Documentación general y guía del repositorio. 
| scrip_servicio_dental.sql , Script SQL con la creación de tablas, llaves primarias (PK), foráneas (FK) y relaciones normalizadas. 
| script_exploratorio.R , Script en R para el análisis exploratorio y procesamiento de datos del servicio dental. 
| ProyectoIntegrador_ServicioDental.pdf , Documentación completa del proyecto con el Modelo Conceptual y Relacional. 


## 🗄️ Modelo de Base de Datos

El diseño de la base de datos fue corregido y estructurado siguiendo las mejores prácticas de modelado relacional:
* Normalización: Estrictamente estructurado hasta la Tercera Forma Normal (3FN).
* Diagrama Entidad-Relación (DER): Incluye la definición clara de entidades y relaciones del servicio médico-dental.
* Llaves y Tipos de Datos:* Especificación detallada de tipos de datos, llaves primarias (PK) y llaves foráneas (FK) para garantizar la integridad referencial.


## 📊 Análisis Exploratorio (.R)

El script en R realiza las siguientes tareas sobre la información recolectada:
1. Importación y limpieza de datos clínicos y operativos.
2. Análisis estadístico descriptivo de los servicios dentales prestados.
3. Visualización exploratoria de datos para la toma de decisiones.


## 🚀 Pasos para Ejecutar el Proyecto

1. Base de Datos:
   * Importar y ejecutar el archivo scrip_servicio_dental.sql en tu manejador de base de datos.
2. Análisis en R:
   * Abrir el archivo .R en RStudio o tu entorno de preferencia y ejecutar el script exploratorio.
